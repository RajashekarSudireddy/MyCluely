# Design Language Guide
### Personal Brand: AI & Tech Content (X-first)

## 1. Design Inspiration
Visual language inspired by Factory.ai's product design: minimal SaaS/dashboard aesthetic,
sharp geometric structure, quiet technical precision, generous negative space, zero decorative
fluff. Typography inspired by Google Sans: geometric, structured, confident, highly legible.

## 2. Core Design Principles
- Minimal over decorative. Every element must earn its place.
- 14px corner radius on UI-like shapes.
- Generous negative space; avoid visual clutter.
- One accent color used sparingly, never as a dominant fill.
- No literal AI cliches: no robots, glowing brains, circuit-brain mashups, generic "AI art" look.
- No text or logos baked into generated images (add text separately if needed, in Google Sans).

## 3. Color Palette

| Role | Color | Hex | Usage |
|---|---|---|---|
| Primary background | Near-black / charcoal | #020202 - #0A0A0A | Base background for all visuals |
| Accent (primary) | Vivid orange | #EF6F2E | Sparse highlight: thin lines, single shape, key data point |
| Secondary structural | Muted cool grey | #6A7282 | Grid lines, secondary text, dividers |
| Text (on dark) | Off-white | #F5F5F5 | Primary text on dark backgrounds |
| Text (muted) | Light grey | #A1A1AA | Captions, secondary labels |

Rule of thumb: 90% neutral (black/grey/white), 10% or less orange accent.

## 4. Typography
- Primary typeface: Google Sans (fallback: Google Sans Text for body copy, Google Sans Flex
  for flexible weight needs).
- Headlines: Bold/Medium weight, geometric, tight letter spacing.
- Body/captions: Regular weight, slightly looser spacing for legibility at small sizes.
- Avoid script, serif, or decorative fonts entirely. No mixing typefaces.

## 5. Layout & Composition
- Grid-based composition; align elements to an invisible grid, avoid free-floating decoration.
- Keep bottom-left third empty/dark on X header images (profile photo overlap zone).
- Prefer flat, 2D layouts over 3D renders or heavy shadows/gradients.
- Use thin lines and subtle grid overlays over bold illustrations.

## 6. Image Generation Prompt Template
Use this as the base prompt for any future AI-generated visual asset:

"Minimal SaaS dashboard aesthetic, deep charcoal-to-near-black background (#020202-#0A0A0A),
sharp geometric grid layout, 14px corner radius, generous negative space. Single vivid orange
accent (#EF6F2E) used sparingly - one line, shape, or highlight only. Muted cool grey (#6A7282)
for secondary structural elements. Any letterforms should evoke Google Sans: geometric,
structured, confident. No robots, no glowing brains, no cliche AI imagery, no literal circuits,
no text, no logos. Feel: engineered, confident, premium - like a serious technical product
interface, not AI-generated stock art."

## 7. Asset Specs Reference

| Asset | Dimensions | Notes |
|---|---|---|
| X header | 1500x500 px (3:1) | Bottom-left third stays empty for profile photo overlap |
| X profile photo | 400x400 px min | Real photo, not AI-generated |
| Instagram post (square) | 1080x1080 px | Phase 2, apply same palette/typography |
| Instagram Reel cover | 1080x1920 px | Phase 2 |
| YouTube thumbnail | 1280x720 px | Phase 3, keep same accent color for brand recall |

## 8. Consistency Checklist (Before Publishing Any Visual)
- [ ] Background is near-black/charcoal, not another color
- [ ] Only one orange accent element, used sparingly
- [ ] Corner radius is 14px on structural/UI-like shapes
- [ ] No literal AI cliches (robots, brains, generic circuits)
- [ ] Typography matches Google Sans style if any text/letterforms appear
- [ ] Composition feels minimal and grid-based, not busy or decorative
- [ ] Matches the tone: engineered, credible, premium
