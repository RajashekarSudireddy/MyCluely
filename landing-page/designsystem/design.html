Design language guide

Personal Brand: AI & Tech Content

A minimal, engineered, premium visual system for X-first AI and tech content. The system borrows from precise SaaS dashboards: near-black surfaces, 14px corners, generous negative space, and one restrained orange accent.

This HTML file is the human-readable mirror of the provided design.md. It renders the same palette, typography, composition rules, asset specs, prompt template, and publishing checklist in one browser-ready reference.

01 / Inspiration

Factory-style technical restraint

The design language is minimal SaaS/dashboard rather than expressive illustration. It should feel precise, structured, and credible, with every visual element aligned to a grid and every accent used deliberately.

02 / Principles

Minimal over decorative

The system is designed to prevent generic AI visuals. It should stay geometric, restrained, and legible, with no decorative filler and no literal AI cliches. Use this as a taste boundary, not a source to clone: every asset, composition, and layout should be original to this brand.

Do

  • 01Use grid-based structure and clear alignment.
  • 02Use a 14px corner radius on UI-like shapes.
  • 03Let negative space carry the premium feel.
  • 04Use orange only as a sparse highlight.

Don't

  • 01Do not add robots, glowing brains, generic circuits, or AI stock-art tropes.
  • 02Do not bake text or logos into generated images.
  • 03Do not use the orange accent as the dominant fill.
  • 04Do not recreate another brand's exact assets, page layouts, animations, or recognizable compositions.
  • 05Do not use a corner radius other than 14px.

03 / Colors

Neutral field, single orange signal

The palette is approximately 90% neutral and 10% or less orange. Near-black owns the background, off-white owns primary text, grey supports structure, and orange identifies the one thing that matters most.

04 / Typography

06 / Shapes and depth

Flat, 14px corners

Use flat 2D surfaces, borders, thin lines, and subtle grid overlays. Every UI shape uses a 14px corner radius. Avoid heavy shadows, glossy gradients, and 3D renders.

--radius14px

Preferred: flat

Border-only structure keeps the system precise.

Allowed: line depth

A subtle inset line is enough to create hierarchy.

Avoid: glow

Large orange shadows quickly become generic and overproduced.

08 / Prompt template

Base prompt for generated visuals

Use this prompt as the system's repeatable generation anchor. Text and logos should be added separately after generation, never baked into the image.

Minimal SaaS dashboard aesthetic, deep charcoal-to-near-black background (#020202-#0A0A0A), sharp geometric grid layout, 14px corner radius, generous negative space. Single vivid orange accent (#EF6F2E) used sparingly - one line, shape, or highlight only. Muted cool grey (#6A7282) for secondary structural elements. Any letterforms should evoke Google Sans: geometric, structured, confident. No robots, no glowing brains, no cliche AI imagery, no literal circuits, no text, no logos. Feel: engineered, confident, premium - like a serious technical product interface, not AI-generated stock art.

10 / Publishing checklist

Consistency before publishing

Run this list against every visual. It protects the brand from drifting into busy, decorative, or generic AI imagery.

  • Background is near-black or charcoal, not another color.
  • Only one orange accent element is used, and it is sparse.
  • Corner radius is 14px on structural and UI-like shapes.
  • No literal AI cliches appear: robots, brains, or generic circuits.
  • Assets and layouts are original to this brand, not copied from any reference site.
  • Layout scale matches the scale lock: 1120px container, 420px hero, 56px display type, 220px section label rail, and 14px corner radius.
  • Typography matches the Google Sans style if any text or letterforms appear.
  • Composition feels minimal and grid-based, not busy or decorative.
  • The final tone reads engineered, credible, and premium.
